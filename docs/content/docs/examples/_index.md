Complete ChangeWindow manifests for common maintenance tasks. Each page explains
selection, audience, and the expected result. Downloadable YAML comes directly
from the repository's validated examples. Each complete YAML file deploys its
ChangeWindow and matching ServiceAccount together. Action examples also bundle
narrowly scoped executor RBAC; adapt controller identities and workload namespaces
using the [security guide]({{< relref "/docs/guides/security#executor-permissions" >}}).

Start with the [interactive YAML on the homepage]({{< relref "/#window-example-title" >}})
for a guided tour of the complete API flow.
