# Change Windows

Scheduled maintenance and resource automation for Kubernetes.

Change Windows helps platform teams coordinate maintenance, prevent conflicting
changes, and warn users before work begins. Automate routine tasks such as scaling
workloads down after hours and restoring them in the morning.

Use it with Capsule or on its own, with your existing Kubernetes platform and
deployment tools.
